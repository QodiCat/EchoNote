# UI 设计上下文

## 当前阶段

EchoNote 已完成首版 PRD 确认，但暂不进入业务开发，当前阶段为 UI 设计与交互确认。

## UI 目标

设计 Windows 10+ 免安装桌面应用的核心操作流程：

- 首次启动配置本地保存目录。
- 开始录音、录音中、停止录音。
- 录音结束后的转录处理中状态。
- 转录成功、失败和错误提示。
- Markdown 是否包含时间戳的用户选择。
- 本地录音与 Markdown 同时删除及二次确认。

## 设计边界

- 只录制电脑播放的系统声音，不提供麦克风录音入口。
- 不设计录制过程中的实时转录界面。
- 不设计音频回放、录音重命名、搜索、列表管理或自动更新功能。
- 音频与文字最终只保存在本地；服务端代理相关状态需要明确提示，但不展示或暴露凭据。

## UI 设计门禁

- 先完成页面结构、交互流程和关键状态，再进入业务开发。
- 所有异常状态必须有明确反馈和用户可理解的下一步操作。
- 关键操作不能依赖静默状态变化：开始、停止、删除、目录配置和转录失败都要有可见反馈。
- 设计稿确认前，不将 UI 资产视为已批准，不开始对应功能开发。

## 预期产物

- 主界面与核心状态原型。
- 首次配置目录流程。
- 录音到转录完成的状态流转。
- 删除确认流程。
- 错误状态清单及对应提示文案。
- UI 资产 ID 与 PRD 功能 ID 的对应关系，回填到 `.product/phase-1/echonote-v1-traceability.md`。
