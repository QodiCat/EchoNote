# UI 设计上下文

## 当前实现

用户已明确要求保持 UI 简约、突出功能、减少无用介绍。主界面已移除宣传侧栏、装饰圆球、英文栏目和重复说明，改为单栏：录音卡片 → 保存设置 → 最近一次结果。

- 录音卡片突出计时、开始/停止按钮和中文状态，标明系统声音来源。
- 保存设置包括目录和 Markdown 记录时间选项；目录未配置时显示操作提示。
- 最近结果显示保存路径与删除入口，不提供历史列表或文本编辑器。
- 右上角“设置”打开快捷键弹窗，可分别保存开始和结束的全局组合键；留空关闭。
- 全局快捷键触发会显示主窗口；设置弹窗打开时禁用快捷键开始，停止仍可用；录音流程有防重入。

## 事实与授权

实现文件为 src/index.html、styles.css、renderer.js、settings.css、settings.js。快捷键与精简界面分别记录在 .product/phase-1/recording-shortcuts.md 和 ui-simplification.md。用户增量请求不等于整体 PRD 或视觉稿最终验收通过。

19 项自动测试通过；浏览器不可用，未完成视觉检查。实际 Windows 快捷键、不同窗口尺寸、长目录显示及错误提示仍需手工验证。

## 保留边界

只录系统声音，停止后转录，不提供麦克风、实时字幕、回放、重命名、搜索、历史列表和自动更新。保留开始/停止、目录、转录错误及删除确认的必要反馈，不用装饰性说明替代操作信息。

## 2026-10-05 转录设置

用户授权桌面管理代理、填写凭据和打包。设置新增独立火山引擎表单：APP ID、密码型 Access Token、加密存储说明及状态/错误反馈。快捷键独立保存。成功保存或关闭弹窗清空凭据输入；未配置禁止录音。弹窗支持滚动，录音或转录期间禁止在界面修改凭据。

2026-10-05：最近一次结果增加“打开文件夹”按钮，转录保存成功后与删除按钮并列显示；打开期间禁用防连点，错误由 toast 提示；删除最近结果后一起隐藏。
