# 架构上下文

## 当前实现

仓库目前没有应用源码、依赖清单、构建配置、测试框架、CI 或部署配置。不存在可继承的技术栈。

## 已知产品边界

1. Windows 桌面端。
2. 用户主动开始录音。
3. 读取电脑当前播放的音频；是否同时读取麦克风尚未确认。
4. 用户结束录制后处理为文本。
5. 支持将文本保存为 Markdown。

## 尚未决策的架构问题

- Windows 最低版本与发布/安装方式。
- 桌面框架、语言及音频捕获 API。
- “实时转录”是录制中实时产出，还是录制结束后处理。
- 本地转录、云端转录或可切换方案。
- 支持语言、时长上限、处理时延与准确率目标。
- 音频和文本的本地存储、删除、恢复及隐私授权策略。

技术栈必须在需求边界确认并完成可行性验证后选择；初始化阶段不写业务代码。
