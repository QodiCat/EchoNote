# 测试与验证

## 当前状态

已建立 Node/Electron 脚本：`npm test` 和 `npm run lint` 执行 JavaScript 语法检查；`npm run dev` 启动桌面 MVP；`npm run build` 依赖 Electron Builder。依赖安装和真实 Windows 音频捕获尚未验证。

## 首版质量门槛

- 在 Windows 10+ 验证系统播放音频捕获，不得采集麦克风。
- 验证开始、录音中、停止、处理中、成功和失败状态。
- 验证录音结束后才发起 STT 请求，不产生实时转录界面行为。
- 验证中文、英文及标点输出；验证用户选择带或不带时间戳的 Markdown 结构。
- 验证音频文件和 Markdown 写入同一用户配置目录，且目录只需首次启动配置。
- 验证删除操作同时删除录音和 Markdown；任一删除失败必须可见。
- 覆盖无系统音频、权限拒绝、网络中断、代理错误、火山引擎错误、磁盘不足和保存失败。
- 验证转录失败后本次流程结束，下一次必须重新开始录音。
- 验证代理链路不持久化音频、文字或可还原内容，日志不泄露敏感数据。
- 验证免安装运行方式；自动更新不属于本期验收范围。

技术栈建立后，只依据实际配置补充准确命令；不虚构验证结果。
