# 技术债与风险

## 当前缺口

- 未完成需求澄清，尚无批准 PRD、功能 ID 或验收标准。
- 未选择桌面框架、语言、音频捕获方案和转录方案。
- 未定义 Windows 版本、安装发布方式、离线要求及第三方服务。
- 未定义录音与转录数据的隐私、存储、保留和删除规则。

## 主要风险

- 系统播放音频捕获与麦克风捕获是不同能力，不能混为一谈。
- 云端转录会引入敏感音频传输、费用、网络和服务可用性问题。
- 本地转录会影响安装包体积、硬件要求和处理时延。
- 长录音需要明确磁盘空间、崩溃恢复和中断处理策略。

## 建议顺序

1. 完成 `.product/requirements-intake.md` 的阻断性澄清。
2. 形成并由用户批准首版 PRD 及四份配套文件。
3. 验证 Windows 系统音频捕获可行性，再确定技术栈。
4. 用户明确批准后，才进入首个功能的开发 Loop。
