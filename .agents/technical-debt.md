## 已实现但尚未验收

系统音频来源修复、WebM 到 WAV、上游 JSON 协议与错误码处理、环境加载、全局快捷键、录音防重入和简约界面均有代码。19 项自动测试通过，但桌面实录、后台快捷键、完整保存删除和发布包仍需实测。

## 工程缺口

- Markdown 时间选项当前仅写保存时刻，未使用上游 utterances，录音偏移时间戳语义需核实。
- 代理尚无客户端鉴权或访问控制，监听地址未限制为回环；不应视为可直接对外部署的服务。
- 部分 URL、端口、超时仍在源码中有默认值，与 AGENTS.md 的配置约束不完全一致。
- 录音和请求整段驻留内存，并有 WAV/Base64 额外开销；代理大小上限和上游限制与“不设最长时长”需求之间存在缺口，未实现分片与崩溃恢复。
- 客户端断连未联动取消上游请求；请求大小超限时连接销毁可能导致客户端只看到网络错误。
- 保存两文件不具备事务性；文件名冲突可能覆盖，删除 Promise.all 失败时可能已经删除其中一个文件。
- 失败录音不落盘，最近结果不跨重启保留；不要误认为具有录音库管理能力。
- 代理内存依赖垃圾回收，不能保证立即擦除；部署日志、交换文件和崩溃转储尚未核验。
- 打包版代理地址配置不完整；没有完整 portable 发布验证，也没有 CI。
- tests/lint 脚本的语法检查范围不覆盖所有源码，lint 不是完整 lint 工具。
