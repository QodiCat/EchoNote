# 产品工作启动提示词

执行产品工作时，先阅读根目录 `AGENTS.md`、相关 `.agents/` 和本目录入口；区分用户事实、分析意见、提案和已批准目标。

## 本项目当前门禁

1. 先完成 `requirements-intake.md` 中的阻断性澄清。
2. 用户确认理解无误后，才撰写标准 PRD 与同前缀的 `schedule-quote`、`delivery-status`、`traceability` 四份文件。
3. 用户明确批准 PRD 后，才可选择功能 ID、确定技术栈并进入开发 Loop。
4. 当前阶段不开发业务功能，不把候选方案写成既定事实。

## 文件职责

- `.product/`：产品目标、范围、验收和交付状态。
- `.agents/`：架构、测试、部署等工程事实。
- `AGENTS.md`：项目入口、真实命令和全局约束。

每次阶段结束都要输出：已确认事项、未解决问题、阻断原因、对验收的影响和下一步入口。用户核对无误并明确授权前，不开始开发。
