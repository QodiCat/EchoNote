# 产品工作启动提示词

执行产品工作时，先阅读根目录 `AGENTS.md`、相关 `.agents/` 和本目录入口；区分用户事实、分析意见、提案和已批准目标。

## 本项目当前门禁

1. 先阅读当前交付状态、实际实现和需求记录；不要沿用“尚未开发”的旧阶段描述。
2. 现有 PRD、商务、交付和追踪文件继续维护，不重复创建同类文档。
3. 全局 PRD 批准记录存在历史冲突，缺少证据时保留待核实，不根据代码或测试追认批准。
4. 用户在当前会话中明确授权的增量和修复可以推进，并记录对应范围；不得扩展为未请求的产品承诺。
5. 自动测试、真实桌面联调、发布构建和客户验收分别记录，不能互相替代。

## 文件职责

- `.product/`：产品目标、范围、验收和交付状态。
- `.agents/`：架构、测试、部署等工程事实。
- `AGENTS.md`：项目入口、真实命令和全局约束。

每次阶段结束都要输出：已确认事项、未解决问题、阻断原因、对验收的影响和下一步入口。用户核对无误并明确授权前，不开始开发。
