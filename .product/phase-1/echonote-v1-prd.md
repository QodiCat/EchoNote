# EchoNote v1 · PRD 版本 0.1

状态：PRD 待批准

## 1. 产品与范围

EchoNote 是 Windows 10 及以上的免安装桌面应用。用户主动开始后，应用只录制电脑播放的系统声音；用户停止后，将音频发送至服务端代理，通过火山引擎语音识别 STT 转换为中文或英文文本，并保存为 Markdown。服务端代理不持久化用户音频和文字，音频文件与转录文本最终只保存在用户本地目录。

本期不包含：麦克风录音、录制中实时转录、说话人区分、音频回放、录音列表管理、重命名、搜索、时间戳强制输出、账号体系和多目录配置。

## 2. 预期功能

### P1-01 开始录音

用户点击开始后，应用捕获电脑当前播放的系统声音并显示录音中状态。不得采集麦克风。没有可捕获系统声音或捕获失败时，显示明确错误，且不生成成功录音。

### P1-02 停止并转录

用户点击停止后结束录音，应用将本次录音提交服务端代理，由代理调用火山引擎 STT。服务端只做本次请求所需的临时转发和处理，不持久化音频、转录文本或可还原内容。支持中文和英文，输出包含标点。录音结束后统一转录，不要求录制中显示文本。

### P1-03 保存 Markdown

转录成功后，在用户首次启动配置的目录中保存录音文件和对应 Markdown 文件。二者使用同一目录。Markdown 是否包含时间戳由用户选择；未选择时输出纯文本结构。保存失败时显示错误，不得提示成功。

### P1-04 删除记录

用户删除一条记录时，同时删除对应的本地录音文件和 Markdown 文件。删除前需明确提示将同时删除两类文件；任一文件删除失败时显示失败结果，不得静默忽略。

### P1-05 配置

首次启动配置一次保存目录，后续使用该目录；录音文件和 Markdown 不允许分别配置。应用采用免安装运行方式。本期暂不实现自动更新。

## 3. 状态与异常

至少显示：未录音、录音中、处理中、成功、失败。系统音频不可用、权限不足、网络中断、服务端失败、转录失败、磁盘不足和保存失败均需显示对应错误提示。

转录失败后本次录音流程结束；不提供本次任务继续重试，用户需重新点击开始录音。原始录音是否保留需在服务端数据策略和错误处理设计中确认。

## 4. 验收标准

- AC-01：在 Windows 10+ 上点击开始，播放系统音频，点击停止；验证生成本次录音，且麦克风声音不被采集。
- AC-02：停止后验证应用进入处理中并调用火山引擎 STT，中文和英文音频均能得到带标点文本。
- AC-03：验证成功结果和录音文件、Markdown 文件均写入同一用户配置目录。
- AC-04：验证用户可选择 Markdown 是否包含时间戳，并验证两种输出结构。
- AC-05：模拟无系统音频、权限、网络、服务端和磁盘错误，验证出现对应错误提示且不误报成功。
- AC-06：验证转录失败后本次流程结束，必须重新点击开始才能发起下一次录音。
- AC-07：删除一条记录后，录音和对应 Markdown 一并删除，并验证删除失败有明确提示。
- AC-08：验证首次配置目录后重启应用仍使用该目录，且不支持分开配置两个目录。
- AC-09：验证应用可采用免安装方式运行；本期不包含自动更新。
